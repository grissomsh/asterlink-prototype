## 视觉基准

对齐 New API（Semi Design 系）形态：

- 主色 `#0064FA`，内容区浅灰底 `#f9fafb`，白色卡片、8px 圆角、1px 灰边框；
- 控制台为「左侧边栏 + 顶栏 + 内容区」布局，侧边栏按 构建 / 控制台 / 账号 / 管理 分组；管理页用户卡带「管理员」标识；
- 状态徽标语义统一：绿色=可用/成功，琥珀=部分受限/额度将尽，红=失败/过期/熔断，灰=维护/禁用。
